## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. Phase A 출력 직전에 `{SKILL_DIR}`을 이 SKILL.md가 있는 실제 폴더 경로로 바꿔 보여 준다.

```
예지보전 10분 실습을 준비해 줘.

1. 내 홈 폴더 아래에 pdm-lite 폴더를 만들어 줘.
2. {SKILL_DIR}/assets/lab/Day5_설비센서_50건_가상.csv 를 pdm-lite/ 로 복사해 줘. 원본은 수정하지 마.
3. 행 수와 열 이름을 보여 줘. 한글이 깨지면 UTF-8로 다시 읽어 줘.
4. Python 3(python, python3, py 순서로)과 gh 로그인 상태를 확인해 줘. 없거나 로그인이 안 되어 있으면 설치·로그인하지 말고 알려만 줘.
5. 결과를 pdm-lite/env_check.txt 에 적어 줘. 비밀번호나 토큰을 묻지 마.
```

### 확인할 것 (Phase B)

- `~/pdm-lite/Day5_설비센서_50건_가상.csv`가 50행이다.
- `~/pdm-lite/env_check.txt`에 Python 버전과 gh 로그인 상태가 적혀 있다.
- gh 로그인이 안 되어 있으면 Block 2 전에 강사에게 알린다(Block 1은 그대로 진행할 수 있다).

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
pdm-lite 준비가 어디서 막혔는지 env_check.txt와 폴더를 보고 원인을 찾아 줘. 고치기 전에 무엇을 바꿀지 먼저 말해 줘.
```
