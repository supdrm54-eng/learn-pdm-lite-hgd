## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| 평상 범위 | 평균 ± 2표준편차. 평균만으로는 "얼마나 벗어났는지"를 판단할 수 없다 |
| 이상 후보 | 평상 범위를 벗어난 값. 설비별로 따로 계산한다 |
| 노이즈 | 한 번 튀고 곧 정상으로 돌아오는 일시적 값. 측정 오류·순간 외란일 수 있다. 한 점의 이상치는 정비 신호가 아니다 |
| 추세 | 임계선을 향해 꾸준히 오르는 흐름. **이 상승의 시작점이 정비 필요 시점** — "고장 전 계획 정비"의 기준점 |

### 2. 한 점을 볼 것인가, 흐름을 볼 것인가

| 기준 | 임계선을 넘은 한 점만 본다 | 흐름의 시작점을 본다 |
|---|---|---|
| 한 번 튄 값 | 정비 신호로 오인 | 노이즈로 보고 지나간다 |
| 꾸준한 상승 | 넘은 뒤에야 안다 | 오르기 시작한 때 안다 → 계획 정비 |

### 3. 원본 실습과제 2

원본 강의는 두 수열 **[1.0 → 1.1 → 0.9 → 3.5 → 1.0]**과 **[1.0 → 1.3 → 1.7 → 2.2 → 2.9]** 중 어느 쪽이 정비 신호인지 물었다. 오늘 데이터에서 이 두 수열이 어디서 나왔는지 찾는다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
pdm-lite 폴더의 센서 CSV로 진동의 노이즈와 추세를 판정하고 그래프 한 장을 만들어 줘.

1. 진동(mm/s) 열만 쓰고, 설비A와 설비B를 따로 나눠 평균, 표준편차(표본표준편차, n-1), 평상 범위(평균 ± 2 × 표준편차)를 계산해 줘.
2. 평상 범위를 벗어난 값을 "이상 후보"로 표시해 줘.
3. 이상 후보마다 판정해 줘: 다음 시점에 평상 범위로 돌아오면 "노이즈", 직전부터 계속 오르다가 범위를 넘었으면 "추세".
4. 추세로 판정한 설비는 범위를 처음 넘은 값에서 거슬러 올라가, 직전 값보다 커지는 일이 끊기지 않고 이어진 구간 중 가장 이른 시각(처음 오르기 시작한 시각)을 "정비 필요 시점"으로 적어 줘.
5. 결과를 judgement.md 에 [설비 / 평상 범위 / 이상 후보 / 판정 / 정비 필요 시점] 표로 저장해 줘.
6. index.html 한 장에 그래프 하나만 그려 줘: 가로축 시각, 설비A·설비B 진동 선 2개, 각 설비의 평상 범위 상한 점선, 이상 후보 빨간 점, 정비 필요 시점 세로선. 외부 서버 없이 파일 하나로 열리게, 맨 위에 "실습용 가상 데이터" 표시, 휴대폰에서 가로로 넘치지 않게.
7. 다 만들면 index.html 을 열어 보여 줘.
```

### 확인할 것 (Phase B)

- 설비A 평상 범위 0.09~2.10 mm/s, 이상 후보 12:40 3.5 → 노이즈.
- 설비B 평상 범위 0.30~2.08 mm/s, 이상 후보 15:40 2.2·16:00 2.9 → 추세, 정비 필요 시점 15:00.
- 이상 후보는 모두 3건이다.
- `index.html`에 그래프가 하나 있고 빨간 점 3개, 정비 필요 시점 세로선 1개가 보인다.
- 원본 실습과제 2의 두 수열이 설비A 11:40~13:00, 설비B 14:40~16:00 구간이다.
